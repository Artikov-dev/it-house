3-SLAYD — MATN TURI

String Data Type

Matnli ma’lumotlarni saqlash va qo‘shtirnoqlar bilan ishlash

String nima?

String — har qanday matnli ketma-ketlik. Qo‘shtirnoq ("..."), birtirnoq ('...') yoki backtick (`...`) ichida yoziladi.

Qo'shtirnoq mosligi rule:

Agar matn ichida qo'shtirnoq bo'lsa, tashqarisiga birtirnoq ishlatiladi:

"Hello World" LABEL: STRING
string_examples.js 
let name = "Ali";
let city = 'Tashkent';

// String ichida qo‘shtirnoqlar:
let a = "Bu 'yaxshi' fikr";
let b = 'Uning ismi "Ali"';
let message = "Welcome to JavaScript!";

console.log(typeof name); // "string"
console.log(a);
console.log(b);
console.log(message);

4-SLAYD — SONLAR

Number va BigInt

Matematik sonlar, o'nlik kasrlar va o'ta katta butun sonlar

1. Number

Oddiy butun (integer) va o'nlik kasr (decimal) sonlar Number turiga kiradi.

123e5 ➔ 12300000 (Exponential)
123e-5 ➔ 0.00123

2. BigInt

Juda katta butun sonlar uchun ishlatiladi. Oxirida n harfi yoziladi.

25 ➔ Number 25n ➔ BigInt
numbers.js 
let age = 20;
let price = 15.5;
let exp = 123e5;

console.log("typeof age:", typeof age);
console.log("exp qiymati:", exp);

// BigInt (oxirida 'n' bor)
let bigNumber = 1234567890123456789012345n;
console.log("bigNumber:", bigNumber);
console.log("typeof bigNumber:", typeof bigNumber);

7-SLAYD — OBJECT

Object Data Type

Ma’lumotlarni key-value (kalit-qiymat) ko‘rinishida saqlash

Key-Value Struktura

Object bir nechta ma'lumotlarni kalit (key) va uning qiymati (value) juftligida saqlaydi.

firstName: "John"
lastName: "Doe"
age: 20

Array va Date ham typeof bo'yicha "object" qaytaradi!

objects.js 
const person = {
    firstName: "John",
    lastName: "Doe",
    age: 20
};

console.log("Ismi:", person.firstName); // John
console.log("Yoshi:", person.age);       // 20

// Array & Date ham Object:
const cars = ["BMW", "Volvo"];
console.log("typeof cars:", typeof cars); // "object"

8-SLAYD — SYMBOL

Symbol Data Type

Noyob va o‘zgarmas (unique & immutable) identifikator yaratish

Symbol nima?

Symbol har safar chaqirilganda tamomila noyob (unique) va takrorlanmas ID qiymat hosil qiladi.

Symbol("id") ID_#984124A
!==
Symbol("id") ID_#338199B

Bir xil tavsif berilsa ham, ular teng bo'lmaydi!

symbol_test.js 
const id1 = Symbol("id");
const id2 = Symbol("id");

console.log("id1 === id2 :", id1 === id2); // false!
console.log("typeof id1 :", typeof id1);   // "symbol"

// Asosiy tushuncha:
// Symbol -> unique / noyob qiymat
